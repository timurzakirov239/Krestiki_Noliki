## Описание проекта

Проект представляет собой учебную платформу для демонстрации методов машинного обучения на двух задачах:

1. **Анализ вин** — регрессия, классификация и кластеризация на датасете вин с платформы Vivino.
2. **ИИ для крестиков-ноликов** — обучение нейросети игре в крестики-нолики методом «обучение с учителем» .

Всё объединено в **десктопное GUI-приложение** на PySide6, где можно:
- просматривать данные, предсказывать цену и ценовой сегмент вина;
- визуализировать кластеры на 2D scatter-plot;
- играть в крестики-нолики против ИИ и наблюдать процесс обучения «в замедленном режиме».

## Подробное описание компонентов

### 1. Загрузка и подготовка данных (`common.py`)

- Объединяет 4 CSV-файла (Red, White, Rose, Sparkling) в единый DataFrame.
- Нормализует колонки, приводит типы (`Rating`, `Price`, `NumberOfRatings`).
- Обрабатывает год: распознаёт `N.V.` (non-vintage), заполняет пропуски медианой.
- Удаляет строки без цены, рейтинга или с нулевыми значениями.
- Функция `make_features()` формирует числовые и категориальные признаки для моделей.

### 2. Обучение моделей для вин

#### Регрессия (`train_regressor.py`)
- **Задача**: предсказание цены вина.
- **Целевая переменная**: `log1p(Price)` (логарифмическая трансформация для борьбы с выбросами).
- **Модель**: `Ridge(alpha=1.0)` внутри sklearn Pipeline.
- **Препроцессинг**: `SimpleImputer` + `StandardScaler` (числовые), `OneHotEncoder` (категориальные).
- **Метрики**: MAE, RMSE, R² (на обратной шкале — в евро).

#### Классификация (`train_classifier.py`)
- **Задача**: определение ценового сегмента — «дёшево» / «средне» / «дорого».
- **Пороги**: квантили 33% и 66% по цене (рассчитаны **только по train set**).
- **Модель**: `LogisticRegression(max_iter=2000, class_weight="balanced")`.
- **Метрики**: classification report, confusion matrix.

#### Кластеризация (`train_clusterer.py`)
- **Задача**: автоматическая группировка вин по сходству характеристик.
- **Признаки**: `Rating`, `LogPrice`, `LogRatingsCount`, `Year_num`, `YearIsNV`, `WineType`, `Country`.
- **Алгоритм**: `KMeans` с автоподбором k (от 3 до 8) по silhouette score на подвыборке.
- **Снижение размерности**: `TruncatedSVD` (до 50 компонент) + `StandardScaler`.
- **Выход**: CSV с метками кластеров и 2D-координатами для визуализации.

### 3. Модуль крестиков-ноликов (`src/ttt/`)

#### Игровая логика (`ttt_core.py`)
- Представление доски: кортеж из 9 элементов (`X=1`, `O=-1`, `EMPTY=0`).
- Проверка победителя, доступных ходов, терминальных состояний.
- 8 симметрий (вращения + отражения) для аугментации данных.
- Кодирование с точки зрения ИИ (`encode_board_for_ai`): нормализует перспективу — ИИ всегда «видит» свои фигуры как `+1`.

#### Учитель (`ttt_teacher.py`)
- Minimax-алгоритм с мемоизацией (`lru_cache`).
- Три уровня сложности:
  - **senior** — полный minimax (оптимальная игра), 0% шума.
  - **mid** — minimax с глубиной 3, 10% случайных ходов.
  - **junior** — minimax с глубиной 1, 30% случайных ходов.

#### Генерация датасета (`generate_dataset.py`)
- Перебирает **все** достижимые позиции на доске (3⁹ = 19683 комбинации, отфильтрованные по валидности).
- Для каждой позиции учитель выбирает лучший ход.
- Аугментация: каждый пример умножается на 8 (все симметрии доски).

#### Обучение (`training.py`)
- **Модель**: `MLPClassifier` (нейросеть) — 9 входов (клетки) → 9 выходов (вероятности ходов).
- Конфигурация по уровням:
  - **junior**: 1 скрытый слой (16 нейронов), 25 эпох.
  - **mid**: 2 скрытых слоя (32×32), 45 эпох.
  - **senior**: 2 скрытых слоя (64×64), 80 эпох.
- Обучение mini-batch SGD с Nesterov momentum.
- Callback для прогресса (`progress_cb`).

#### Агент (`ttt_agent.py`)
- Epsilon-greedy стратегия: с вероятностью ε делает случайный ход, иначе — ход модели.
- Если модель не загружена — использует учителя (minimax) как fallback.

### 4. GUI-приложение (`src/qt_app/`)

#### Главное окно (`main.py`)
Две основные вкладки:

**«Главная»** — виджет крестиков-ноликов (если доступен):
- Игра против ИИ с выбором стороны (X/O) и уровня сложности.
- Демо обучения: пошаговое обучение нейросети — видно, как модель обучается на каждой позиции.

**«Данные»** — 4 подвкладки:
- **Таблица** — просмотр загруженного CSV, русскоязычные заголовки.
- **Регрессия** — предсказание цены для выбранной строки (модель Ridge).
- **Классификация** — предсказание ценового сегмента (модель LogisticRegression).
- **Кластеры** — scatter-plot с цветовой маркировкой кластеров, автоматические описания (например, «премиальные, высокие оценки, популярные, красные»).

#### Виджет крестиков-ноликов (`ttt_widget.py`)
- **`PlayTicTacToe`**: интерактивная игра — пользователь кликает по клеткам, ИИ отвечает.
- **`SlowSupervisedTrainer`**: визуализация обучения MLP «в замедленном режиме»:
  - Генерация случайных позиций.
  - Учитель (minimax) показывает «правильный ход» (зелёная подсветка).
  - Модель делает свой ход (синяя/красная подсветка).
  - После каждого шага — `partial_fit` на одном примере.
  - Лог с историей обучения.

## Как запустить

### 1. Запуск GUI-приложения
cd src
python -m qt_app.main

### 2. Обучение моделей для вин
cd src
python train_regressor.py
python train_classifier.py
python train_clusterer.py

### 3. Обучение моделей крестиков-ноликов
cd src
python -m ttt.train_all
